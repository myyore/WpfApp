📐 图纸查询与管理系统 (Drawing Query System)
这是一个基于 C# WPF 开发的现代化桌面端图纸查询与管理工具。系统采用 Windows 11 风格的 Fluent Design 设计语言，完美结合了结构化数据检索与高清 PDF 工程图纸预览，旨在为工程师提供极致丝滑的查图体验。

✨ 核心特性
1. 高效的数据检索与展示
实时搜索：无需回车，输入即搜。支持对图纸名称（Name）及所有参数值（Details）进行模糊匹配。

关键词高亮：搜索结果中，所有匹配的字符自动变为黄底加粗，一目了然。

结构化参数卡片：图纸参数采用 JSON 字典（键值对）存储，UI 自动渲染为“参数名加粗 + 参数值”的流式标签，支持自动换行，排版极其规整。

智能右键复制：在任意图纸卡片上点击右键，可通过智能菜单直接复制【图纸名称】、【零件号】、【图号】或【全部参数】，方便粘贴到其他软件。

2. 智能 PDF 预览弹窗
单例模式：全局仅保留一个图纸弹窗。点开新图自动关闭旧图；再次点击当前图的图标即可关闭。

智能贴边吸附：弹窗会判断屏幕左右空间，紧贴主界面左侧或右侧 20px 自动弹出，绝不遮挡主界面。

路径智能匹配：打开图纸时，程序优先去 Assets/PDFs 目录下寻找与图纸 Name 同名的 PDF 文件，若找不到再尝试通过 PdfPath 字段读取。

一体化旋转：默认采用 A4 竖屏比例（595x842）。点击右上角按钮，窗口、纸张和 PDF 图纸会同步旋转 90 度切换为横屏，完美铺满。

3. 丝滑的图纸交互
🖱️ 滚轮缩放：以鼠标指针为中心无损缩放（支持最大 50 倍放大看细节）。

🖐️ 左键平移：按住左键即可任意拖拽图纸。

🔄 右键旋转：单次点击右键，图纸独立旋转 90°。

🔄 双击重置：双击鼠标左键，瞬间恢复自适应铺满状态。

🛠️ 日常维护指南（如何添加新数据？）
系统采用无代码驱动设计，添加新数据无需修改代码或重新编译。

1. 完整图纸（有 PDF 且有参数）
将 PDF 文件放入 Assets/PDFs/ 文件夹。强烈建议直接以“图纸名称（Name）”命名（如 蜗杆图样.pdf）。

打开 Assets/Data.json，在 [ 和 ] 之间按以下格式新增：

json
  {
    "Category": "外摩擦片",
    "Name": "蜗杆图样",
    "Details": {
      "零件号": "HC038A-01-021",
      "图号": "HC038A-01-022",
      "外径 D": "83",
      "内径 d": "55",
      "齿数": "44"
    },
    "PdfPath": ""
  }
提示：PdfPath 可以留空，程序会自动根据 Name 去找 PDF。与上一条数据需用英文逗号 , 隔开，最后一条无需逗号。

2. 仅有 PDF 图纸（无参数）
直接将 PDF 放入 Assets/PDFs/ 文件夹。

无需修改 JSON。程序启动时会自动扫描，并将其纳入左侧“仅有PDF文件”分类中，你依然可以查看高清原图。

3. 增加左侧大纲新分类
如果你要在左侧增加大类（如“制动器图纸”）：

打开 MainWindow.xaml，搜索 FlatDirectoryList。

在 <ListBoxItem> 集合中添加：<ListBoxItem Content="制动器图纸"/>。

在 JSON 中将对应的 "Category" 填为 "制动器图纸" 即可自动过滤联动。

⚠️ 极其重要的防坑设置
1. VS 文件复制属性
在 Visual Studio 中，新增的文件默认不会被复制到运行目录，会导致程序读取不到数据或图纸。

解决方法：在资源管理器中选中新增的 PDF 或 Data.json -> 右下角“属性”面板 -> 将 “复制到输出目录” 设置为 “始终复制”。

一键解决：直接选中整个 Assets 文件夹，将其“复制到输出目录”设为“始终复制”。

2. 程序图标配置
必须使用 .ico 格式的图标，放入 Assets 文件夹。

文件的 “生成操作” 必须设置为 Resource。

如果遇到“找不到资源”报错，检查 XAML 中的路径大小写是否与文件夹完全一致（如 Icon="Assets/AppIcon.ico"）。

3. Visual Studio 缓存卡死
如果在运行或编写 XAML 时突然出现大面积 XDG0008（命名空间不存在）等莫名其妙红叉报错，但代码本身没问题：

关闭 VS -> 删除项目 bin 和 obj 文件夹 -> 重新打开 VS 重新生成，或直接重启 VS 即可解决。
